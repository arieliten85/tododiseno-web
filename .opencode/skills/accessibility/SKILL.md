# Accessibility

- Prefer semantic HTML landmarks, headings, lists, buttons, and links.
- Follow basic WCAG expectations for contrast, focus, labels, and keyboard access.
- Use buttons for actions and links for navigation.
- Keep focus visible and never remove outlines without replacing them.
- Add labels, descriptions, and clear error messages to forms.
- Treat dialogs as focus-managed interactions before adding them.
- Write useful alt text for meaningful images; use empty alt only for decorative images.
- Respect reduced motion when adding animation.
