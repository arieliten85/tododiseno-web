# Frontend quality

- Check mobile-first responsive behavior.
- Verify visual consistency, spacing rhythm, typography, and semantic design tokens.
- Avoid hardcoded brand colors or business text inside reusable components.
- Confirm performance basics: minimal client JS, server-rendered SEO, and optimized images.
- Check accessibility: landmarks, heading order, focus states, labels, and alt text.
- Keep Server/Client Component boundaries intentional and small.
- Reuse existing UI and section components before adding new primitives.
